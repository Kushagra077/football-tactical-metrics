# Reports

This directory holds two committed validation artifacts:

- `validation.json` — metrics vs. synthetic ground truth + published physiological ranges
- `sensitivity.json` — how each metric moves when the smoothing window / thresholds change

Both are written by `python -m scripts.validate`. They are committed on purpose,
so the accuracy claims in the README can be checked without rerunning anything.

`figures/` holds PNGs generated by `ftm.viz` and embedded in the README.
